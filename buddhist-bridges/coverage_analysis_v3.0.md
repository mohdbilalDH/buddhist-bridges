## 6. Genuine imbalance vs collection bias

**Genuine historical imbalance (do not "fix" by padding):**
- **B3 = 0 carried rows.** Joseon (1392–1900) was a closed, Neo-Confucian state; Buddhist India contact was minimal. The only realistic lead (Yi Kyu-gyŏng's India entries in Oju yŏnmun changjŏn san'go) is a research gap, not a missing record. This emptiness is historically meaningful — it marks the network's long interruption.
- **B2 (13) vs B1 (46)**: the Goryeo network is real but smaller; the Jikong circle (4 people) is now complete. The "16 Goryeo monks" claim is unverified — do not inflate B2.
- **B5 (11) thin**: post-liberation Buddhist India contact was genuinely sparse until the 1980s (documented negatives: Kelaniya twinning unrealised, no Nav Nalanda Koreans pre-Pŏpchŏng).

**Collection bias (fixable in future rounds):**
- **B6 (59) is the best-documented band** — it reflects source availability (Korean Buddhist press, institutional websites), not necessarily greater historical weight. Any B6-vs-B1 comparison must control for source density.
- **Events (19) are all B5/B6** — contemporary developments are event-shaped; historical ones are person-shaped. Do not read the event table as a historical series.
- **News-heavy source mix** (NEWS=51, TERTIARY=43, WEBSITE=27 vs PRIMARY=13, ARCHIVAL=15): the ancient/medieval core rests on a small set of primary/archival sources; the contemporary layer rests on news. Confidence tiers differ by band — analyse accordingly.
- **Korean-language source dominance**: Korean Buddhist press (beopbo, hyunbulnews, ibulgyo) is over-represented vs Indian sources; Indian-side corroboration is a future priority.

## 7. What the coverage supports

- **B1**: a defensible network analysis of Silla–Tang–India Buddhist mobility (Hyecho, Woncheuk, the Silla monk cluster, sacred-site geography).

- **B5/B6**: a contemporary-institution network (19 events, 31 institutions, pilgrimages/MOUs/relic transfers) — descriptive, not causal.
